Comment utiliser l’app

Jouer en 1v1 Discord + filmer / enseigner les échecs et le Go. Pas un site de tournois.

1. Choisir le jeu

  1. Ouvrez le hub.
  2. Cliquez Échecs ou Go → Jouer / Teaching / Vidéo.

2. 1v1 Discord

  1. Test local : mock Go ou mock Échecs.
  2. Activity réelle : lanceur Discord (HTTPS + Client ID requis — voir docs/DISCORD.md).
  3. Échecs : hôte = Blancs, invité = Noirs.
  4. Go : hôte = Noir, invité = Blanc.

3. Filmer (OBS / YouTube)

  1. Onglet Vidéo → Broadcast / OBS.
  2. Copiez Lien OBS → Browser Source (fond transparent).
  3. Optionnel : Webcam, Timeline leçon (export JSON pour le montage).
  4. Spectateur distant : Lien Watch (PeerJS observe=1) après une partie connectée.

4. Teaching

  • Échecs : Classroom (expliquer / essayer / proposer), flèches, PGN.
  • Go : Take Control, marques, leçons, SGF, quiz.
